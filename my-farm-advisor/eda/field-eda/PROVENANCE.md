# Field EDA Provenance

## Origin

- Created 2026-11-20 in this repository on branch `assignment-2` for Assignment 2.
- Original code. No third-party analysis package is vendored; the subskill uses
  the runtime's existing `pandas`, `geopandas`, `numpy`, `scipy`, and
  `matplotlib` installs and imports `field_frame` helpers from the installed
  data-pipeline source for map padding.
- It does not modify pipeline data, schemas, or the farm/grower tree.

## Data sources

| Layer | Source | Terms and notes |
| --- | --- | --- |
| Field polygons (OSM subset) | OpenStreetMap via the data pipeline's Overpass bootstrap, written to `boundary/field_boundaries.geojson` | ODbL 1.0; retain OpenStreetMap attribution |
| Field polygons (CSB subset) | USDA NASS Crop Sequence Boundaries via FIBOA GeoParquet, downloaded by `download_csb_fields.py` | CC-BY-4.0 (FIBOA) / USDA public |
| Crop history | USDA NASS Cropland Data Layer, summarised by `download_cdl.py` into `<prefix>_cdl_*_full_composition.csv` | USDA public data |
| Weather | NASA POWER via the pipeline's Zarr backend, written to `<prefix>_weather_*_.csv` | NASA POWER, public; gridded, not on-farm measurement |
| County corn maturity | `shared/corn_maturity/tables/rm_by_fips_*.parquet`, produced by `strategy/maturity-by-fips` from the canonical county weather tables | Derived from the same NASA POWER source; heuristic relative maturity, not a hybrid or seed recommendation |
| County soybean maturity | `shared/soybean_maturity/tables/mg_by_fips_*_average.parquet` | Latitude regression; reported as a reference value, not a heat test |
| Farm and grower labels | Runtime `farm.json` / `grower.json` | Generated by the data pipeline |

The figures in `examples/output/` are derived from the public sources above.
They contain no personal or proprietary farm data.

## Analytical decisions

### Geometry

- Area and perimeter are computed in EPSG:5070 (CONUS Albers, equal-area), not in
  degrees. `area_acres` from the boundary file is kept only for cross-checking.
- Compactness is `4πA/P²`: 1.00 for a circle, 0.785 for a square. Values below
  about 0.5 mean elongated or ragged geometry.
- Orientation is the bearing of the minimum rotated rectangle's long edge,
  unwrapped to (−90°, 90°].
- Size and boundary source are confounded in this dataset, so the analysis
  reports both the per-grower area–compactness correlation and the CSB-versus-OSM
  rank comparison, and the output says so in its own header note.

### Crops

- Dominant crop per field-year is the class with the largest CDL percentage.
- Crop composition is the mean percentage across available years, renormalised
  to the classified total so the bar sums to 100%. The renormalisation is
  recorded in the caption; the raw table keeps the unnormalised values.
- Corn-after-corn counts field-years where corn follows corn, over the number of
  corn field-years with a preceding year in the window.
- Shannon diversity is computed over the five-year dominant-crop counts per field.

### Weather

- Growing degree days use base 10 °C and no upper cap:
  `max((T2M_MAX + T2M_MIN) / 2 − 10, 0)`, summed daily.
- The seasonal window is April–September, matching the pipeline's CDL years.
- Heat stress counts days with `T2M_MAX > 35 °C`.
- NASA POWER is a gridded product. The subskill counts distinct grid cells per
  grower (0.5° latitude by 0.625° longitude) and reports that count with every
  weather result. Within-grower field differences are therefore grid artefacts,
  and the analysis says so rather than ranking fields.

### Maturity

- Two GDD definitions are used on purpose and are never mixed. The weather
  category uses April–September with base 10 °C and no upper cap. Maturity fit
  uses the whole calendar year, base 10 °C and a 30 °C cap, duplicating
  `maturity_by_fips.compute_county_gdd` so the field and county values come from
  one definition.
- The county requirement is `rm_relative_maturity × 20 GDD per RM`, the same
  linear rule the maturity product applies to its own five-year GDD total. The
  county RM is taken from the five-year average file that matches the weather
  years, not from a different window.
- A field-year is below target when its full-year GDD is lower than the county
  requirement. Shortfall is reported in GDD and in RM points (÷ 20).
- A *season* is counted as short only when the grower's mean field GDD for that
  year is below the requirement. Counting a season short because one field in it
  dipped would overstate the signal, so the season verdict and the field-year
  count are kept separate and both are labelled.
- The county target is built from the county weather table, not from the ten
  fields in this run, so a persistent level offset is location, not management.
  The result is a per-grower verdict; it is not used to rank fields.
- Soybean maturity is a latitude regression with no GDD threshold, so it is
  carried as a reference value in A4 and excluded from the shortfall test.
- No yield, as-applied, or economics input exists in the runtime. No figure or
  table here claims crop performance, cost, or profit.

### Statistics

- Correlations are Spearman rank correlations with a seeded bootstrap interval.
- Two-group comparisons use Mann–Whitney U with a rank-biserial effect size.
- Categorical association uses a chi-square test with Cramér's V.
- Weather variance is attributed descriptively by sum-of-squares shares between
  growers, between years within growers, and within grower-years. No model is fit
  and no significance is claimed at the field level.

## Figure decisions

- Grower colour is fixed by state code (IL, IA, NE) so the same grower keeps the
  same colour in every figure. Crop colours are fixed by class so a map and a bar
  chart agree.
- Maps are farm overviews in a local UTM frame: kilometre ticks from the farm
  extent's south-west corner, 4% viewport pad, boxed north arrow, scale bar.
  Auto-rotation is deliberately not applied because a farm is not a single
  footprint.
- No figure carries a timestamp, so a re-run with unchanged inputs is visually
  reproducible.
- F7 is a dot plot, not a bar chart: the y-axis is zoomed to the plausible GDD
  range, and a bar from zero would hide both the target line and the field
  spread. The shared y-axis keeps the three growers comparable.
