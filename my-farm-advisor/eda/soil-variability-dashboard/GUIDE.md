# Workflow: soil-variability-dashboard

## Description

Generate a standalone HTML dashboard that analyzes soil variability across all
fields for a given grower. The dashboard includes soil pH, NDVI, OM, CEC,
drainage class, weather, soil health scores, and multi-metric radar charts,
along with decision-support text to guide field management actions.

## When to Use

- **Cross-field soil analysis**: Compare soil properties across every field in a grower.
- **Crop planning**: Identify nutrient constraints, drainage issues, and productivity patterns.
- **Remediation targeting**: Find low-pH, low-OM, or poorly drained fields for intervention.
- **Seasonal monitoring**: Check NDVI as a ground-truth on whether soil constraints are limiting yield.
- **Reporting**: Generate a shareable, self-contained HTML report for operators.

## Prerequisites

```bash
pip install -r requirements.txt
```

`DATA_PIPELINE_DATA_ROOT` must point to a writable runtime root containing the
grower's data tree (generated by the farm data pipeline).

## Usage

```bash
export DATA_PIPELINE_DATA_ROOT=/home/coder/my-farm-advisor-runtime

# Generate dashboard for il-northern-grower (all farms)
python src/dashboard.py \
  --grower-slug il-northern-grower \
  --output output/soil_variability_dashboard.html
```

The output is a self-contained HTML file that opens in any browser.

## Dashboard Sections

| Section | Contents |
|---------|----------|
| KPI Summary | Field count, total acres, avg NDVI, rainfall, soil health score, erosion risk |
| Exploratory Visualizations | Soil pH distribution, NDVI by field/crop, OM/CEC/pH correlation |
| Geospatial Analysis | Map of field boundaries coloured by soil health score |
| Weather & Climate | Monthly precipitation, daily temperature envelope |
| Soil Health & Sustainability | Composite health score, drainage class pie, multi-metric radar |
| Decision Support Summary | Interpretive text with actionable recommendations |

## Output Interpretation

- **pH < 6.0**: Lime recommended to raise to target 6.5.
- **Soil health < 50**: Priority fields for cover crops, drainage, or variable-rate amendment.
- **NDVI < 0.6**: Crop stress visible — investigate soil, drainage, or pest causes.
- **Poor drainage + low health**: Strong candidates for tile drainage investment.
- **High OM, balanced pH, high CEC**: Benchmark fields to replicate across the farm.
