# Soil Variability Analysis Dashboard

Generates a standalone HTML dashboard for soil variability analysis across all
fields of a grower. Aggregates SSURGO soil data, weather, NDVI, and field
boundaries from every farm under the grower into a single decision-support
report.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Set the data-pipeline runtime root
export DATA_PIPELINE_DATA_ROOT=/home/coder/my-farm-advisor-runtime

# Generate the dashboard for a grower
python src/dashboard.py \
  --grower-slug il-northern-grower \
  --output output/soil_variability_dashboard.html
```

Open `output/soil_variability_dashboard.html` in any browser.

## File Structure

| Path | Purpose |
|------|---------|
| `src/dashboard.py` | Entry point — CLI argument parsing, HTML assembly, KPI card rendering |
| `src/data_loader.py` | Loads and aggregates grower-level data across **all farms** |
| `src/figures.py` | One function per Plotly chart; all figure, KPI, and annotation logic |
| `app.py` | Dash application stub for migrating to live server mode |
| `AGENTS.md` | Agent instructions for this subskill |
| `GUIDE.md` | Comprehensive usage guide with interpretation notes |
| `requirements.txt` | Python package dependencies |
| `output/` | Generated HTML output |

## Figures

- **Soil pH Distribution** — bar chart with target pH 6.5 reference line
- **Average NDVI by Field** — grouped bar chart by crop (corn/soybean)
- **Soil Properties Correlation** — three subplots: OM %, CEC, pH
- **Geospatial Soil Health** — choropleth map of soil health scores
- **Monthly Precipitation** — bar chart of cumulative monthly rainfall
- **Daily Temperature Envelope** — max/mean/min temperature lines
- **Composite Soil Health Score** — colour-coded bar chart (green/amber/red)
- **Drainage Class Distribution** — pie chart by drainage class
- **Field Variability Radar** — multi-metric polar comparison per field

## Data Source

The dashboard reads from the canonical My Farm Advisor data tree under
`${DATA_PIPELINE_DATA_ROOT}/data-pipeline/growers/<grower_slug>/`. This data is
generated by the farm data pipeline (see `data-pipeline/AGENTS.md`).
