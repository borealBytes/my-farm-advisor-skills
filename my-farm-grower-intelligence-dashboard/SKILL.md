# My Farm Grower Intelligence Dashboard

**Domain:** Agricultural Data Science & Farm Management  
**License:** Apache-2.0

---

## Purpose

Generate an interactive, grower-level HTML dashboard that synthesizes
field boundaries, soil health, multi-year crop history, NASA POWER weather,
and Sentinel-2 NDVI into five coordinated visualizations for operational
intelligence and sustainability assessment.

## Routing Guidance

- Use this skill when the user asks for a **grower-level dashboard**,
  **row crop intelligence summary**, or **farm sustainability overview**.
- Requires an initialized My Farm Advisor runtime with field boundaries,
  SSURGO soil, NASA POWER weather, USDA CDL, and Sentinel-2 rasters already
  generated by the data pipeline.
- Output is a single self-contained HTML file with embedded interactive
  Plotly charts.

## Runtime Notes

This skill is a document-routed workflow. The runnable script lives under
`scripts/generate_grower_dashboard.py` and is executed from the runtime copy
at `${DATA_PIPELINE_DATA_ROOT}/data-pipeline/src`.

## Data Notes

All input datasets are farm-level derived tables already produced by the
`my-farm-advisor` data pipeline. The script performs one lightweight
on-the-fly computation — Sentinel-2 NDVI zonal statistics per field — and
caches the result for subsequent runs.
